ICU university corpus

The ICU corpus is fragmented, multilingual, and multi-format. It contains ICU-related institutional knowledge spread across multiple domains and represented in different formats.

Our goal is to include as much data from ICU-related official or linked sources as possible, so that the system can cover a wider range of student questions.

Corpus construction

We collect raw data from the sources mentioned above. However, raw web data contains many headers, boilerplate sections, navigation texts, and repetitive text blocks that appear across web pages because of the HTML structure.

We then apply source-aware chunking. Instead of using one fixed chunking strategy for every source, we use different chunking strategies for different source types.

ICU Bench 30

ICU Bench 30 is a benchmark question set that contains 30 questions designed to evaluate student-facing university QA over the ICU corpus.

The question set covers three languages: English (20), Japanese (7), and Chinese (3). We also included non-answerable questions on purpose to test whether the model can answer from evidence, use good citations, and avoid over-answering.
