System30 Hidden-State Trajectory Case Study

Teacher-forced hidden-state diagnostics for Qwen3.5 0.8B bad answers against matched Qwen3.5 2B/4B references.

hidden statesSystem30Qwenbad casestrajectory

What This Run Tests

This update is a first hidden-state case-study gallery for System30 bad answers. The target is Qwen3.5 0.8B, because the System30 sweep showed several cases where the model repeated itself, copied retrieved evidence into the answer, mixed languages, or over-answered from weak evidence.

The run uses saved System30 answers rather than newly generated answers. For each selected answer, the model is run in teacher-forced mode over the original generated text, and hidden states are extracted for the generated answer tokens. This keeps the analysis tied to the exact answers that were already judged in the System30 evaluation.

Experiment Design

  • Source answers: System30 model/mode sweep.
  • Bad target: Qwen3.5 0.8B low-quality or repetitive answers.
  • References: Qwen3.5 2B and/or Qwen3.5 4B on the same question and answer mode.
  • Cases: 6 matched groups, 15 extracted trajectories.
  • Layers: approximately 50%, 75%, 90%, and final layer.
  • Main representations: generated-token states, cumulative generated-token mean states, sentence/step mean states, recurrence matrices, local PCA projections, and scalar trajectory features.

Important limitation: hidden dimensions differ across model sizes, so raw hidden vectors are not directly subtracted across models. The comparison uses scalar trajectory features and per-answer local PCA/recurrence plots.

Main Diagnostic Result

The clearest signal is text-level repetition. Across the selected groups, Qwen3.5 0.8B bad cases have much higher repeated 4-gram counts than the larger references.

  • Qwen3.5 0.8B bad cases: mean human quality 0.229, mean repeated 4-grams 71.2, mean cumulative recurrence over .95 is 0.0101.
  • Larger Qwen references: mean human quality 0.917, mean repeated 4-grams 21.6, mean cumulative recurrence over .95 is 0.0064.

The hidden-state signal is suggestive but not yet a final detector. Cumulative recurrence is higher on average for 0.8B bad cases, but not uniformly higher in every matched group. Entropy is also mixed, so it should not be used alone.

Case Examples

The strongest failure is s30_023 in agentic mode. Qwen3.5 0.8B copied evidence-like text into the answer and produced 269 repeated 4-grams, while the 2B and 4B references were much more usable.

The s30_014 case was changed to single-shot mode so the selected models use the same retrieved context. The 0.8B answer is repetitive and truncated, while the 4B reference is more usable under the same evidence.

The s30_017 case replaces the earlier course-list example, which mostly reflected similar course-record formatting rather than a clear generation collapse. In s30_017, the same course appears in both Spring and Autumn syllabus records; 0.8B fails to separate the term-specific grading policies, while both 2B and 4B handle the two offerings correctly.

How To Read The Trajectory Plots

The PCA plots are local to each answer trajectory. They show how the cumulative mean of generated-token hidden states moves over the generated answer. The recurrence matrices show cosine similarity among cumulative hidden states; blocky high-similarity regions can indicate repeated or loop-like generation states.

Aligned Cross-Model 3D Trajectories

The first 3D viewers above are local PCA plots, so their axes are not shared across model sizes. To test whether a more direct visual comparison is possible, this follow-up experiment learns a supervised linear alignment into the Qwen3.5 4B anchor space.

The alignment uses 240 teacher-forced calibration samples from ICU-related passages and high-quality System30 answers. The held-out 0.8B bad cases are not used for training the mapping. Validation is done with paired retrieval on held-out calibration samples and a shuffled-pair baseline.

In this run, both 0.8B-to-4B and 2B-to-4B mappings recover the paired held-out sample at retrieval@1 = 1.000, while shuffled baselines stay low. This means the aligned-space visualization is at least structurally meaningful for these calibration samples. It is still exploratory and should not be treated as proof that the raw hidden spaces are naturally shared.

The CKA heatmaps also show high cross-scale layer similarity inside the Qwen3.5 family, especially around the later layers.

The aligned shared-space plots below place 0.8B, 2B, and 4B trajectories into one visual coordinate system after alignment. These plots are most useful as case-study figures; the scalar feature PCA remains the safer cross-model summary.

Example recurrence plots for the strongest repetition case, s30_023:

This pair is more visually representative of evidence-dump repetition than s30_014: the 0.8B answer is much longer and copies evidence-like text, while the 2B reference is compact and has no repeated 4-grams. The recurrence heatmap should still be read as a supporting diagnostic, not as a standalone detector.

Because the recurrence plots above use cumulative hidden-state means, later prefixes can naturally become smoother and more similar. This update therefore adds four supplementary diagnostics for the same s30_023 pair:

1. raw final-layer token hidden-state recurrence, without cumulative averaging; 2. sliding-window hidden-state recurrence, using local windows instead of all previous tokens; 3. exact text 4-gram recurrence, computed from the decoded answer text; 4. repeated-token-span overlays on the local PCA trajectory.

For s30_023, these checks do not make the hidden recurrence claim dramatically stronger. The raw-token and sliding-window recurrence plots are less decisive than the original cumulative plot. The clearest signal remains the output-level repetition: Qwen3.5 0.8B has 269 repeated word 4-grams, while Qwen3.5 2B has 0. The hidden-state path metrics still support this difference: the 0.8B cumulative path length per token is 3.50, while the 2B reference is 10.98, suggesting that the 0.8B trajectory moves less per generated token during the long evidence-dump answer. The repeated-span trajectory overlay uses tokenizer-level repeated 4-grams, so it can show a few markers even when the word-level repeated 4-gram count is zero.

Interpretation

This first run supports a cautious claim: small-model bad answers can be organized into a hidden-state trajectory diagnostic, but the most reliable signal in this pass is still repetition in the output text. Hidden recurrence and path-length features are promising supporting signals, not a finished classifier.

For the thesis, this is best used as a small case study rather than a main quantitative result. It motivates a future question: whether repetition, copy-dump behavior, or over-answering can be detected before the answer is complete.
